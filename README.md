# My Dotfiles

- `.zshrc` - Zsh configuration
- `.vimrc` - Vim configuration

## Zsh

- Plugin manager: [Oh My Zsh](https://ohmyz.sh)
- Customizable prompt: [Starship](https://starship.rs)
- Command line tools:
    - Command line fuzzy finder: [fzf](https://github.com/junegunn/fzf)
    - A smarter cd command: [zoxide](https://github.com/ajeetdsouza/zoxide)
    - Rewrite ls command: [lsd](https://github.com/lsd-rs/lsd)

## Vim

- Plugin manager: [vim-plug](https://github.com/junegunn/vim-plug)
- Themes: [sonokai](https://github.com/sainnhe/sonokai)
- Language packs: [vim-polyglot](https://github.com/vim-polyglot/vim-polyglot)
- File system explorer: [NERDTree](https://github.com/preservim/nerdtree)
- Language Server Protocol manager: [coc.nvim](https://github.com/neoclide/coc.nvim)
    - C LSP: [coc-clangd](https://github.com/clangd/coc-clangd)
    - Markdown LSP: [marksman](https://github.com/yaegassy/coc-marksman)
    - Explorer extension: [coc-explorer](https://github.com/weirongxu/coc-explorer)
    - Multi-Selection: [vim-visual-multi](https://github.com/mg979/vim-visual-multi)
    - Selection Region: [vim-expand-region](https://github.com/terryma/vim-expand-region)
    - Beautiful status/tabline: [vim-airline](https://github.com/vim-airline/vim-airline)
    - Type icons for vim plugins: [vim-devicons](https://github.com/ryanoasis/vim-devicons)
